Potion Blast

Potion Blast

Roles

  • Programador
  • Diseñador de Mecánicas

Resumen

  • Programación en C# en Unity, uso de interfaces y patrones de diseño (Jet Brains Rider)
  • Implementación de sistemas de ayuda de juegos plataformas como Coyote time o Input memory
  • Optimización de sistemas y código en recursos y nomenclatura manteniendo un espacio organizado
  • Uso de Unit tests para automatizar parte del testeo y evitar subir nuevos bugs con las actualizaciones
  • Sesiones de QA periódicas para ajustar gamefeel, valores de daño y encontrar bugs
  • Diseño de mecánicas esenciales del jugador y elenco de habilidades de poderes (Miro y Paint)
  • Gestión de distintas ramas en git en un proyecto dividido en dos repositorios (Sourcetree)
  • Shaders con Shadergraph y Amplify Shader para habilidades y UX, incluido creación de texturas (Inkscape)
